# 唐诗三百首 · 水墨笺注

一个以**古风 / 水墨**视觉呈现《唐诗三百首》的静态阅读网站。按体裁分卷，每首提供**原文、译文、注释、赏析**四部分，纯 `HTML / CSS / JS` 实现，不依赖任何框架与构建工具。

> 双击 `index.html` 即可在浏览器中打开，无需服务器、无需安装依赖。

---

## 特性

- **七卷分章**：按《唐诗三百首》传统体裁划分卷目
  - 卷一 · 五言古诗（10 首）
  - 卷二 · 七言古诗（10 首）
  - 卷三 · 七言乐府（8 首）
  - 卷四 · 五言律诗（17 首）
  - 卷五 · 七言律诗（11 首）
  - 卷六 · 五言绝句（14 首）
  - 卷七 · 七言绝句（21 首）
  - 共 **91 首**，每首含原文 / 译文 / 注释 / 赏析
- **水墨古风**：宣纸渐变底色 + 纸张纤维纹理、三重远山 SVG 晕染、朱红印章、楷体标题、封面式留白
- **竖排阅读**：原文支持 `横排 ↔ 竖排` 切换，偏好记忆到 `localStorage`
- **卷目导航**：左侧七卷可折叠目录 + 顶部体裁快速筛选（全部 / 五古 / 七古 / …）
- **全文搜索**：题名 / 诗人 / 诗句检索，关键词高亮，防抖 160ms
- **路由直达**：`#/wulv-01` 跳转到指定诗篇，`#?q=明月` 为可分享的搜索结果页
- **便捷阅读**：上一首 / 下一首 / 随机；键盘 `←` `→` 翻页、`/` 聚焦搜索
- **响应式**：移动端抽屉式目录，适配窄屏
- **打印友好**：内置打印样式，可直接打印或导出 PDF

## 扩展诗库

诗库集中在 `js/data.js` 的 `CHAPTERS` 数组中，结构如下：

```js
const CHAPTERS = [
  {
    id: 'wulv',        // 卷目英文标识（用于 URL，如 #/wulv-01）
    name: '卷一 · 五言古诗',
    poems: [
      {
        t:  '题名',
        a:  '作者',
        c:  ['原文第一行', '原文第二行', ...],   // 每句一行
        tr: '整篇译文（可为多段，用 \n 分隔）',
        nt: [['注释词', '释义'], ...],            // 逐条注释
        ap: '赏析文字'
      }
    ]
  }
];
```

新增诗篇只需往对应卷的 `poems` 数组追加对象即可，目录、索引、搜索、路由都会**自动生成**。诗篇 `id` 由「卷目 id + 序号」拼接（如 `wulv-01`），序号从 `01` 起按数组顺序自动计算。
